# Reference comparison

Primary references: the two lavender mobile app images supplied by the user. Secondary references inform emotion selection, forms, exercise composition and factual progress. This is a patient product adaptation, not a pixel copy of an unrelated task tracker.

Observed rendered results:

- [Mobile light home](screens/390-fr-light-home-viewport.png): compact greeting, illustrated violet action card, three factual summary cards, daily rows and floating translucent five-position navigation (four destinations plus quick add). Twenty-pixel margins and readable task rows follow the primary references' hierarchy.
- [Mobile night home](screens/390-fr-night-home-viewport.png): the same hierarchy on ink/violet surfaces. Text and controls retain their intended contrast and hierarchy.
- [Studio night](screens/390-fr-night-studio.png): distinct original vector art for breathing, grounding, rest, relaxation and private worksheets; consistent spacing and rounded cards. No old garden/3D-heart artwork appears in these rendered views.
- [Emotion selection](screens/390-fr-light-checkin-emotion.png): six original expressive faces and optional progression. [Journey](screens/390-fr-light-journey.png) shows only recorded observations and explicitly identifies missing data; no invented score or improvement claim.
- [Cabinet](screens/390-fr-light-appointments.png) and [private worksheet](screens/390-fr-light-thought.png): compact appointments and structured forms keep the same material, typography and control sizing as the main app.
- [Desktop](screens/1440-fr-light-home.png): a wider content grid and top navigation use the available space while preserving mobile reading order. [Arabic night](screens/360-ar-night-home.png) mirrors navigation and layout with RTL text.

Intentional adaptations: a private initials avatar instead of the reference's 3D character; meaningful healing-wave mark; factual counts instead of streak pressure or a health score; reduced motion follows both OS and saved preferences. Screenshots cover final CSS and are backed by the 600-case real-browser geometry pass. Motion is verified separately with a real-time recording on the published app.
